# Chai Theory — Built By Ruturaj

> An artisanal daylight luxury interactive website featuring 60FPS frame-by-frame scroll scrubbing, zero-gravity food deconstruction, and seamless zero-edge aesthetics.

---

## ✨ Features

- **Daylight Luxury Aesthetic**: High-key warm white (`#FAFAF8`), deep charcoal copy (`#2B2320`), saffron (`#E38A2C`), and terracotta chili (`#C23B22`).
- **Zero-Edge Seamless Vignettes**: All canvases, media cards, and videos dissolve gently into the background with contained radial masks (`ellipse 48% 46% at 50% 50%`), eliminating all rectangular boundary cuts.
- **Immediate Scroll Scrubbing (Zero Dead Scroll)**: 192 high-DPI frame sequences for:
  - **The Grand Thali Architecture**: Masala Dosa, Sambar, Medu Vada, and Coconut Chutney levitating in zero-gravity on the very first notch of scroll.
  - **Zero-Gravity Samosa Geometry**: Radial deconstruction into flaky ajwain crust, spiced Marawari potato, and whole cumin.
  - **1-Meter Filter Coffee Aeration**: Brass filter decoction foaming between dabarah and tumbler.
- **Dynamic HUD Feedback & Popping Callouts**: Live scroll percentage indicator and synchronized pop labels that scale and pop with elastic spring physics.
- **Ambient Three.js Scene**: Geometric botanical and spice particles floating subtly across sections with depth of field and cursor sway.
- **Buttery Smooth Scroll**: Lenis smooth scroll engine synced 1:1 with GSAP `ScrollTrigger`.
- **Mobile & Multi-Device Optimized**: Full touch scrubbing support, responsive typography clamps, and tailored padding for mobile screens.

## 🛠️ Tech Stack

- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animation Engine**: [GSAP](https://greensock.com/gsap/) (`ScrollTrigger`)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **3D Particles**: [Three.js](https://threejs.org/)
- **Typography**: Fraunces & Inter

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/nilban7/mrchay.git
cd mrchay

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```

## 🌐 Deployment to Vercel

This repository is optimized for one-click deployment on [Vercel](https://vercel.com):

1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and select the **`nilban7/mrchay`** repository.
3. Framework Preset: **Vite**.
4. Click **Deploy**.
